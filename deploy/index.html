本页由 Cloudflare Pages 托管 · 部署所需文件均可直接下载 · 镜像由 GitHub Actions 构建并推送到 TCR / DockerHub

一键安装（部署机控制台）

在部署机终端粘贴运行下面这一行，脚本会自动从本 Pages 站点拉取部署文件、生成 .env 并进入交互式控制台（一键部署 / 更新配置 / 重下地图 / 启停 / 状态日志 / 编辑.env / 下载补丁）。

curl -fsSL https://ac-deploy.pages.dev/deploy-console.sh -o deploy-console.sh && bash deploy-console.sh https://ac-deploy.pages.dev
复制

若你的 Pages 域名不是 ac-deploy.pages.dev，把命令里的地址一起替换即可（脚本第二个参数就是来源 BASE_URL）。

快速部署（手动 5 步，或改用上方控制台）

  1. 把本页文件整包下载到部署机，进入该目录。
  2. cp .env.example .env，编辑：IMAGE_TAG（或留 latest）、DOCKER_DB_ROOT_PASSWORD、SOAP_PASSWORD、REALM_ADDRESS、TCR_NS。
  3. 务必先 docker compose pull —— 从 TCR/DockerHub 拉镜像，漏这步会在服务器本地触发编译。
  4. bash inject-config.sh —— 把自定义配置导出到 env/dist/etc/。
  5. docker compose up -d —— 起库 → 导库（含 43 模组 SQL）→ 灌地图 → 起服。

注意：数据库密码在 .env 的 DOCKER_DB_ROOT_PASSWORD（官方 compose 读取），不在 env.ac。首次部署需手动建一个 gmlevel=1 的 webreg 账号（密码与 .env 的 SOAP_PASSWORD 一致），供外部注册服务（Cloudflare Function）SOAP 调用。

完整说明见 README.md。

玩家客户端补丁（给玩家下，不是服务器用）

整包约 3.1 MB（MPQ 本身已压缩，zip 后保持很小，远低于 25 MiB 上限；若未来补丁增大超过 24 MiB 会自动分卷）。复制下面一行，在玩家机器（或服务器）终端粘贴运行，即一键批量下载并自动合并解压（"点一下下一堆"）。

bash <(curl -fsSL https://ac-deploy.pages.dev/download-patches.sh) https://ac-deploy.pages.dev
复制

若你的 Pages 域名不是 ac-deploy.pages.dev，把命令里的地址一起替换即可。运行后把 Data/ 与 Interface/AddOns/ 复制到 WoW 3.3.5a 客户端根目录。地图数据由服务端自带，不在补丁内。
