基于官方 azerothcore-wotlk 原生编排构建 · 镜像由 GitHub Actions 编译 · 本页由 Cloudflare Pages 托管分发

项目简介

这是一套 WotLK（巫妖王之怒 3.3.5a）私服 的镜像源与部署包。原则只有一条：官方的东西一个字不改，只换两个端点，其余全部走"追加"——

  • 编译位置：官方 CI → GitHub Actions
  • 镜像仓库：Docker Hub → 腾讯云 TCR + DockerHub 双推
  • 分发：部署包与玩家补丁 → Cloudflare Pages（国内连 GitHub 不稳，下载走 CF）
  • 模组：43 个社区模组在编译期静态编入核心（MODULES=static）

镜像内含完整数据库基线、43 模组 SQL、社区地图数据；部署机 docker compose up -d 后自动建库、导库、起服。

账号注册

注册

注册由 Cloudflare 侧 承接：本页表单提交到 CF Function（做图形验证 / 限频 / 白名单）后，再调服务端 worldserver 的 SOAP account create 建号（SRP6 由核心自算，密码不落库明文）。
若 CF Function 尚未部署，可用 GM 账号手动建号：docker compose exec ac-worldserver acore account create <账号> <密码> 1。

客户端补丁（AddOns + MPQ）

补丁包含两部分：AddOns（界面/功能插件）+ zhCN MPQ（中文客户端补丁）。
整包 传输约 3 MB（MPQ 是未压缩数据，zip 后能压到这么小），玩家机器解压后还原为 约 48 MB 的 MPQ 给客户端读取。远低于 Cloudflare Pages 单文件 25 MiB 上限。

一键批量下载并合并（"点一下下一堆"，需 bash 环境：部署机 / Git Bash / WSL）：

bash <(curl -fsSL https://ac-deploy.pages.dev/download-patches.sh) https://ac-deploy.pages.dev
复制

运行后把解压出的 Data/ 与 Interface/AddOns/ 复制到 WoW 3.3.5a 客户端【根目录】即可。地图数据由服务端自带，不在补丁内。

Windows 用户不想用命令，可手动逐卷下载（合并顺序见清单）：

分卷清单：patches-manifest.txt

一键部署（服务器端）

在部署机（有公网 IP、装好 Docker）终端粘贴运行下面一行，脚本会自动从本 Pages 站拉取部署文件、生成 .env 并进入交互式控制台（部署 / 更新配置 / 重下地图 / 启停 / 日志 / 下载补丁）。

curl -fsSL https://ac-deploy.pages.dev/deploy-console.sh -o deploy-console.sh && bash deploy-console.sh https://ac-deploy.pages.dev
复制

若你的 Pages 域名不是 ac-deploy.pages.dev，把命令里的地址一起替换即可（脚本第二个参数就是来源 BASE_URL）。

使用说明

玩家：

  1. 在本页注册账号（或让 GM 建号）。
  2. 下载客户端补丁并解压到 WoW 3.3.5a 根目录。
  3. 客户端 realmlist.wtf 填上服务器地址（即部署时设的 REALM_ADDRESS），启动游戏登录。

部署者（首次）：

  1. 复制上面的"一键部署"命令运行，按菜单 1 部署。
  2. 编辑 .env：DOCKER_DB_ROOT_PASSWORD（数据库密码）、SOAP_PASSWORD、REALM_ADDRESS（对外地址）、TCR_NS。
  3. 务必先 docker compose pull（漏这步会在服务器本地触发编译）。
  4. bash inject-config.sh 注入自定义配置 → docker compose up -d 起服。

注意：数据库密码在 .env 的 DOCKER_DB_ROOT_PASSWORD（官方 compose 读取），不在 env.ac。
