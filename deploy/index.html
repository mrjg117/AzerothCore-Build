项目简介

这是一套 WotLK（巫妖王之怒 3.3.5a）私服 的镜像源与部署包。原则只有一条：官方的东西一个字不改，只换两个端点，其余全部走"追加"——

  • 编译位置：官方 CI → GitHub Actions
  • 镜像仓库：Docker Hub → 腾讯云 TCR + DockerHub 双推
  • 分发：玩家补丁 + 注册页 → Cloudflare Worker（Static Assets）（国内连 GitHub 不稳，下载走 CF）
  • 模组：43 个社区模组在编译期静态编入核心（MODULES=static）

镜像内含完整数据库基线、43 模组 SQL、社区地图数据；部署机 docker compose up -d 后自动建库、导库、起服。

账号注册

注册

注册由 Cloudflare Worker 承接：本页表单提交到 Worker 的 /api/register（做图形验证 / 限频 / 白名单）后，再调服务端 worldserver 的 SOAP account create 建号（SRP6 由核心自算，密码不落库明文）。
若 Worker 尚未部署，可用 GM 账号手动建号：docker compose exec ac-worldserver acore account create <账号> <密码> 1。

客户端补丁（AddOns + MPQ）

补丁包含两部分：AddOns（界面/功能插件）+ zhCN MPQ（中文客户端补丁）。
整包 传输约 3 MB（MPQ 是未压缩数据，zip 后能压到这么小），玩家机器解压后还原为 约 48 MB 的 MPQ 给客户端读取。远低于 Cloudflare 单文件 25 MiB 上限（即便分卷也只是为了方便批量下载）。

下载后把解压出的 Data/ 与 Interface/AddOns/ 复制到 WoW 3.3.5a 客户端【根目录】即可。地图数据由服务端自带，不在补丁内。

使用说明

玩家：

  1. 在本页注册账号（或让 GM 建号）。
  2. 下载客户端补丁并解压到 WoW 3.3.5a 根目录。
  3. 客户端 realmlist.wtf 填上服务器地址（即部署时设的 REALM_ADDRESS），启动游戏登录。

部署本页（Cloudflare Worker，一行命令）：

  1. 装好 Node.js，进 deploy/ 目录。
  2. 设置机密：wrangler secret put SOAP_PASSWORD（与 worldserver 的 SOAP 密码一致）。
  3. 在 wrangler.toml 填 WORLD_HOST（worldserver 公网域名/IP）、WORLD_PORT=7878、SOAP_LOGIN=webreg。
  4. 一行部署：npx wrangler deploy。玩家访问分配的 *.workers.dev 或你绑的自定义域名。

注意：数据库密码在 .env 的 DOCKER_DB_ROOT_PASSWORD（官方 compose 读取），不在 env.ac。
